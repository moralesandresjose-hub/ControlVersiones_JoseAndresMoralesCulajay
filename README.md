# ControlVersiones_JoseAndresMoralesCulajay

### 📘 Descripción
Este proyecto fue desarrollado en **Apache NetBeans IDE 17** como parte de las prácticas de control de versiones con **Git** y **GitHub**.  
El objetivo es demostrar el uso de commits, ramas y repositorios remotos para gestionar versiones de código.

### ⚙️ Funcionalidades
- Menú principal interactivo en consola.
- Cálculo de promedio de tres notas.
- Determinación del número mayor entre tres valores.
- Cálculo del área de un rectángulo.

### 🧠 Tecnologías utilizadas
- **Lenguaje:** Java SE 17  
- **Entorno de desarrollo:** Apache NetBeans 17  
- **Control de versiones:** Git y GitHub
